Technical Architecture

System Architecture & Data Flow

Deterministic state planning, optimistic UI, and defense-in-depth

1. UI Layer

React 19 components with physical micro-interactions, responsive grids, and accessibility.

2. State Hook

useSmartHome orchestrates optimistic UI updates with honest database rollbacks.

3. Pure Engine

automationEngine.js evaluates plans with zero React/network dependencies. Tested with 27 unit tests.

4. Supabase DB

PostgreSQL 16 with Row Level Security, CHECK constraints, and transactional RPC functions.

Separation of Concerns: The automation engine is pure JavaScript. Given (state, event), it deterministically outputs (nextState, patches, logs).
Dual-Layer Validation: Validates on the client in React for snappy UX, and strictly enforced on PostgreSQL via schema CHECK constraints.
Engineering Triumphs

Highlights, Testing & Lessons Learned

Solving real-world production challenges

⏱️ 400ms Debounced Sliders

Dragging sliders fires 60 events/second. Local draft state keeps 60fps UI responsive, committing a single batch write to Supabase once motion stops.

🔒 Silent RLS Detection

Blocked PostgreSQL RLS updates return 0 modified rows rather than SQL errors. Our service layer detects 0 affected rows and throws an honest UI alert.

✨ Physical State Micro-Interactions

Transitions.dev-inspired spring chevrons (180° overshoot), rolling slot-machine temperature reels, and ISO 7010 signage color tokens.

🧪 27 Automated Vitest Tests

Complete test suite runs in under 15ms. Verifies Away/Night/Home modes, intrusion simulation, emergency overrides, and issue counters.
